# T-Edu

Hệ thống ôn luyện THPT Quốc Gia tích hợp AI.

---

## 📌 Introduction

T-Edu là nền tảng học tập trực tuyến hỗ trợ học sinh THPT ôn luyện cho kỳ thi THPT Quốc Gia bằng công nghệ AI.

---

## 🚀 Features

- AI Recommendation System
- Adaptive Learning Roadmap
- Online Mock Exam
- AI Chat Assistant
- Learning Analytics
- Course Management
